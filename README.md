# 众神派对 · 日常挂机

> 个人自用存档，基于 [MaaFramework](https://github.com/MaaXYZ/MaaFramework) 把对应游戏的日常任务自动化。
> 任务逻辑都写在 `assets` 里，欢迎直接 copy 改造。
> 有需要直接 copy 改造即可，不用问我，也无需另行告知。
> 模拟器仅在 Mumu 模拟器上测试过。

## 它能做什么

基于 `assets/interface.json` 配置，自动完成以下日常任务：

- **🎮 进入游戏**：自动启动游戏。
- **🛒 购物中心日常领取**：进入购物中心领取每日免费礼包。
- **📮 友情点领取**：进入好友界面领取友情点。
- **🚀 区域派遣**：进入区域探索进行派遣。
- **🏛️ 联邦悬赏**：进入联邦悬赏进行派遣。
- **⚔️ 刷体力-声波裂隙**：刷取声波裂隙。
- **⚔️ 刷体力-声之神迹**：刷取声之神迹。
- **⚔️ 刷体力-祭祀神迹**：刷取祭祀神迹，并选择具体目标。
- **📋 领取任务奖励**：进入任务界面领取循环任务奖励。
- **📮 领取邮箱**：领取邮件奖励。

> 在 MaaFramework 启动器的任务列表中勾选 / 取消对应项，即可自定义要运行的任务。

## 使用前的游戏设置

- 模拟器分辨率建议 **1920 × 1080**
